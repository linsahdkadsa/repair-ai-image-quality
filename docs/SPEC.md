# 产品需求基线

版本：P00 冻结候选；日期：2026-11-04。本文定义验证平台范围，不代表算法或部署已通过验收。

## 目标与能力边界

平台用于本地图像修复算法验证、结果比较和可复验评估。首要目标是 GPT 迷宫纹/网格噪声修复；另覆盖偏色校正、多轮处理、局部贴回等专用工作流。通用老照片修复、任意去模糊、细节重建不属于效果承诺。算法、模型和可用模式须由 capabilities 与任务记录如实披露，不得以 UI 成功状态替代真实模型执行证据。

## 模块与模式

四个业务模块：

| 模块 | 职责 | 需求 |
|---|---|---|
| 工作台 | 上传、选模式/参数、创建任务、查看进度、比较和下载 | RQ-CORE-01..04 |
| 任务中心 | 查询、查看、取消、重试、恢复人工输入、管理制品 | RQ-TASK-01..05 |
| 评估 | 配对样本、批量任务、指标与报告 | RQ-EVAL-01..04 |
| 系统 | 能力、依赖、模型和存储诊断；受限管理操作 | RQ-SYS-01..03 |

七类模式：

| ID | 模式 | 首版能力声明 |
|---|---|---|
| MODE-01 | 基础纹理修复 | GPT 迷宫纹/网格噪声；真实算法待 P01 确认 |
| MODE-02 | 颜色校正 | Banana 偏色；P07 验收 |
| MODE-03 | 多轮链式处理 | 显式输入顺序与逐步产物；P07 验收 |
| MODE-04 | 局部贴回 | 几何/掩码语义待 P07 样本确认 |
| MODE-05 | 人工清洗增强 | 外部清洗结果由用户提供；P10 验收 |
| MODE-06 | 人工超分增强 | 外部超分结果由用户提供；P10 验收 |
| MODE-07 | 局部移植实验 | 实验性、需人工审核；P11 验收或明确禁用 |

实际可用性、参数边界和降级状态由服务端 capabilities 返回。未验证的模式须显示 unavailable/pending，不可模拟成功。

## 身份、角色和数据

首版单实例、命名用户；不承诺完整多租户。角色：viewer 可查看授权范围；operator 另可创建、取消、重试自己的任务和评估；admin 另可配置、诊断、查看脱敏日志和清理，跨用户访问必须审计。后端认证身份决定 owner，不接受客户端 ownerId。

输入为受支持格式的图片及模式绑定角色；任务输出包含原始输入引用、实际算法/模型版本与哈希、参数、状态、产物元数据、跳过/降级原因和耗时。样本须合法、脱敏并与真实数据隔离；真实样本集和身份集成在 P00 均未提供证据。

## 交付级别

| 级别 | 需求 | 阶段验收 |
|---|---|---|
| M1 | 真实身份上传图片，真实基础修复，进度/比较/下载，并记录执行或降级 | P06 真实端到端 |
| M2 | M1 加颜色、链式、贴回、任务管理、诊断、批量评估和可复验报告 | P09 核心产品 |
| M3 | M2 加人工增强、实验移植能力判定、Windows 离线部署和恢复 | P12 目标机验收 |

计划路线为随上游 ONNX/OpenCV CPU 本地推理；这是待 P01 验证的假设，不是已确认依赖。基础离线能力不以云密钥、GPU 或 SeedVR2 为前提。云服务/额外模型缺少真实条件时保持禁用。

## 冻结的界面基线

默认中文、浅色；主色 `#1677ff`；基础字号 14px；间距仅使用 4/8/12/16/24/32px；表格默认每页 20 条；语义色映射 Ant Design Token。1440、1024、768px 视口验收，768px 时比较区纵向堆叠。

低保真布局（仅信息架构，不代表实现）：

```text
工作台 1440: [导航] [模式/参数与上传 4列] [进度 3列] [前后比较 5列]
任务列表:    [导航] [筛选/状态] [任务表格: 任务|模式|状态|创建时间|操作]
任务详情:    [导航] [状态/阶段] [输入与参数] [产物比较] [事件/诊断]
评估:        [导航] [样本集/模式/指标] [批次进度] [结果表/报告导出]
系统:        [导航] [依赖/模型/存储状态] [能力可用性] [受限管理操作]
768px:       导航折叠；所有并排面板改为单列；关键操作仍在内容顺序内
```

## 测量与可访问性基线

候选预算沿用前端标准：LCP P75 ≤ 2.5s、INP P75 ≤ 200ms、CLS P75 ≤ 0.1。固定验收实验环境拟为 Windows 11 x64、Chrome 稳定版（记录完整版本）、1440×900/1024×768/768×1024、loopback、本机 FastAPI 与 Vite；P05 固定实际浏览器版本、CPU/内存、电源模式、字体、构建模式及网络节流配置后方可形成可复验数据。至少 5 次冷启动、每次 20 次交互，报告中位数与 P75；该小样本只作实验室代理，不代表真实用户 P75。页面渲染/交互与推理耗时分开记录；推理按输入像素分层，具体样本数和像素桶待 P01 样本基线确认。

键盘用例：全流程 Tab/Shift+Tab 不丢焦点；对话框打开焦点进入标题/首控件、关闭回到触发器；每个输入有可访问名称；状态变化可被辅助技术感知；取消/删除有键盘可达确认。比较工具必须提供非拖动操作：原图/结果单独查看、键盘可调分割位置并读出当前百分比，或并列视图；P05 固化为组件测试与 Playwright 用例。实际屏幕阅读器验收环境在 P05 指定。
