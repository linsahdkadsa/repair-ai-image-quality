# 手动洗图（没有配置 API 时）

1. 打开 Gemini（gemini.google.com）或 Google AI Studio（aistudio.google.com），选 Nano Banana / 图片模型。
2. 每次上传「待洗」里的一张图，粘贴下面的提示词，生成。
3. 下载结果，文件名保留原图名字（比如原图 123_枕头.png → 123_枕头_洗.png），放进「洗好的放这里」。
4. 回到 Claude Code / Codex 说「洗好了」，或运行：

   run.sh controller run <原图们> --washed "G:\project\RepairAiImage\docs\evidence\P01\results\controller-manual\washed\洗好的放这里"

## 提示词

适用于：D01_mazey.png

```
Keep this image exactly the same: same composition, framing, product shape, buttons, labels, text, people, lighting, colors and background. Only re-render the velvet / fabric surfaces so they look clean, soft and natural like a real photo, removing the squiggly maze-like noise texture.
```
